Autenticación con SimpleJWT

Los endpoints comerciales de ventas, compras e inventario están protegidos. Obtén tu token JWT y envíalo en la cabecera Authorization:

# 1. Obtener Token JWT: curl -X POST http://127.0.0.1:8000/api/auth/token/ \ -H "Content-Type: application/json" \ -d '{"username": "tu_usuario", "password": "tu_password"}' # 2. Consultar Productos con Token: curl -X GET http://127.0.0.1:8000/api/productos/ \ -H "Authorization: Bearer <tu_access_token>" # 3. Consultar Ventas del Día (@action personalizada): curl -X GET http://127.0.0.1:8000/api/ventas/ventas-del-dia/ \ -H "Authorization: Bearer <tu_access_token>"
